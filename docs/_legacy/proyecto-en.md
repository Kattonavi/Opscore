Problema
Build an incident management system that allows reporting failures from any device, tracking resolution, and analyzing recurring root causes to reduce the frequency of critical incidents.

Descripción
OpsCore is digitizing the operations of an industrial plant with 400 operators. When a machine failure, accident, or quality deviation occurs, it is recorded on paper or via WhatsApp. There is no traceability, response times are not measured, and root causes recur because there is no systematic learning.

Expectations
Mobile-optimized reporting form accessible from an operator's cell phone. Monitoring dashboard with open, in-process, and closed incidents. Root cause analysis module with classification by type and area. Response time and resolution rate metrics per period.

Users
Operator reporting an incident from the production line. Supervisor assigning responsibility and monitoring progress. Plant manager analyzing patterns and root causes.

Workflow
Operator detects a fault → opens the form on their phone → completes the incident type, area, and brief description → submits it → supervisor receives the alert → assigns a responsible technician → technician resolves and closes the incident with the applied solution → the system records the resolution time → manager reviews the weekly root cause analysis and identifies recurring patterns.
