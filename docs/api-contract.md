# API Contract — OpsCore

> Status: design phase. This is the target REST contract. The interactive spec (Swagger UI / OpenAPI JSON) is generated by the backend in dev/staging at `/swagger-ui/index.html`.

## 1. Conventions

| Aspect | Convention |
|---|---|
| **Base path** | `/` (e.g. `https://api.opscore.example`) |
| **Format** | JSON request and response bodies (`application/json`). |
| **Auth** | `Authorization: Bearer <jwt>` on every endpoint except `POST /auth/login`. |
| **IDs** | 64-bit integers (`Long`). |
| **Timestamps** | ISO-8601 (`2026-06-01T14:32:00`). |
| **Enums** | Serialized as their string name (see [Database Model §3](database-model.md#3-enumerations)). |
| **Validation** | Bean Validation; failures return `400` with field messages. |

## 2. Error Envelope

All non-2xx responses share one shape:

```json
{
  "timestamp": "2026-06-01T14:32:00",
  "status": 403,
  "error": "Forbidden",
  "message": "No puedes modificar este incidente porque no está asignado a ti.",
  "path": "/incidents/42/start"
}
```

### Status codes

| Code | Meaning |
|---|---|
| `200 OK` | Success with body. |
| `201 Created` | Resource created. |
| `204 No Content` | Success, no body. |
| `400 Bad Request` | Validation / malformed input. |
| `401 Unauthorized` | Missing or invalid token. |
| `403 Forbidden` | Authenticated but not permitted (contextual message). |
| `404 Not Found` | Resource does not exist or is not visible to the caller. |
| `409 Conflict` | Business-rule violation (e.g. assigning a non-technician). |
| `500 Internal Server Error` | Unexpected failure. |

## 3. Authentication

### `POST /auth/login`
Public. Exchanges credentials for a JWT.

**Request**
```json
{ "email": "operator@opscore.local", "password": "secret" }
```
**Response `200`**
```json
{ "token": "<jwt>", "tokenType": "Bearer", "expiresIn": 86400 }
```
**Errors:** `401` invalid credentials or inactive account.

## 4. Incidents

| Method & Path | Roles | Description |
|---|---|---|
| `POST /incidents` | OPERATOR | Create an incident. |
| `GET /incidents` | All | List, filtered by caller's role/scope; optional `status`, `priority`, `areaId` query params. |
| `GET /incidents/paginated` | All | Paginated list (`page`, `size`, `sort`). |
| `GET /incidents/{id}` | All (scoped) | Incident detail. |
| `GET /incidents/{id}/assignments` | All (scoped) | Assignment history. |
| `GET /incidents/{id}/timeline` | All (scoped) | Audit timeline. |
| `POST /incidents/{id}/annotations` | All (scoped) | Add a timeline comment. |
| `POST /incidents/{id}/assign` | ADMIN, MANAGER, SUPERVISOR | Assign an active technician. |
| `PATCH /incidents/{id}/start` | Assigned TECHNICIAN | `ASSIGNED → IN_PROGRESS`. |
| `PATCH /incidents/{id}/hold` | Assigned TECHNICIAN | `IN_PROGRESS → ON_HOLD`. |
| `PATCH /incidents/{id}/resolve` | Assigned TECHNICIAN | `IN_PROGRESS → RESOLVED`. |
| `PATCH /incidents/{id}/close` | ADMIN, MANAGER, SUPERVISOR | `RESOLVED → CLOSED`. |
| `PATCH /incidents/{id}/cancel` | ADMIN, MANAGER, SUPERVISOR | `→ CANCELED` (from non-terminal states). |

### `POST /incidents` — request
```json
{
  "title": "Falla en línea de envasado",
  "description": "La envasadora 3 se detuvo y muestra error E12.",
  "type": "MACHINE_FAILURE",
  "priority": "HIGH",
  "isFalseAlarm": false,
  "areaId": 2
}
```
> `reportedById`, `assignedToId`, and `supervisorId` are **ignored** if sent. The reporter is always the authenticated operator; assignment happens via `POST /incidents/{id}/assign`.

### Incident response shape
```json
{
  "id": 42,
  "title": "Falla en línea de envasado",
  "description": "La envasadora 3 se detuvo y muestra error E12.",
  "type": "MACHINE_FAILURE",
  "status": "OPEN",
  "priority": "HIGH",
  "isFalseAlarm": false,
  "areaId": 2,
  "areaName": "Envasado",
  "reportedById": 7,
  "reportedByName": "Ana Operadora",
  "assignedToId": null,
  "assignedToName": null,
  "supervisorId": null,
  "supervisorName": null,
  "createdAt": "2026-06-01T14:32:00",
  "updatedAt": "2026-06-01T14:32:00"
}
```

### `POST /incidents/{id}/assign` — request
```json
{ "assignedToId": 15 }
```
**Errors:** `409` if target is not an active `TECHNICIAN`; `409` if the incident is `RESOLVED`/`CLOSED`/`CANCELED`.

### Lifecycle action requests
`start` / `hold` / `resolve` / `close` / `cancel` accept an optional comment recorded on the timeline:
```json
{ "comment": "Repuesto reemplazado, máquina operativa." }
```

### `POST /incidents/{id}/annotations` — request
```json
{ "comment": "Se solicitó repuesto al almacén." }
```

### Timeline entry shape
```json
{
  "id": 88,
  "action": "STARTED",
  "comment": null,
  "userId": 15,
  "userName": "Luis Técnico",
  "createdAt": "2026-06-01T15:10:00"
}
```

## 5. Users

| Method & Path | Roles | Description |
|---|---|---|
| `POST /users` | ADMIN | Create a user. |
| `GET /users` | ADMIN | List users. |
| `GET /users/{id}` | ADMIN | Get a user. |
| `GET /users/assignable` | ADMIN, MANAGER, SUPERVISOR | Active technicians for assignment selectors. |
| `GET /users/me` | All | Current authenticated user. |
| `PATCH /users/me` | All | Update own `firstName` / `lastName` (regex-validated, rejects digits). |
| `PATCH /users/{id}/role` | ADMIN | Change a user's role. |
| `PATCH /users/{id}/status` | ADMIN | Activate / deactivate. |
| `PATCH /users/change-password` | All | Change own password. |
| `PATCH /users/{userId}/change-password` | ADMIN, or SUPERVISOR (own area) | Administrative password reset. |

### `POST /users` — request
```json
{
  "firstName": "Luis",
  "lastName": "Técnico",
  "email": "luis@opscore.local",
  "password": "initial-secret",
  "roleId": 4,
  "areaId": 2
}
```
> The response never includes the password. Welcome email is opt-in and never carries the password.

### `PATCH /users/me` — request
```json
{ "firstName": "Luis", "lastName": "Tecnico" }
```
**Errors:** `400` if a name contains digits.

### `PATCH /users/change-password` — request
```json
{ "currentPassword": "old-secret", "newPassword": "new-secret" }
```
